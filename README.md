# Description
Ce repo a permis de réaliser les analyses nécessaires au projet de l'évaluation de l'effet de l'encadrement des loyers sur l'offre locative de longue durée à Paris et à Lille. 
Afin de ré-executer les analyses, le fichier source avec les données nécessaire a été joint au rendu final. 
Chaque dossier contient ainsi une partie du code éxecutable et testable sous réserve d'avoir installé R et les packages nécessaires.
